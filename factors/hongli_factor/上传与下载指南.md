# 红利策略项目：上传与下载指南

本文用于在两台电脑之间同步 `hongli_factor` 项目、SQLite 数据库和网页代码。

仓库地址：`https://github.com/lightaochen/Investment.git`

## 一、在当前电脑上传最新内容

在项目根目录执行：

```powershell
cd E:\AI-Investment2\Investment
git status
git add .
git add -f factors\hongli_factor\node_modules
git commit -m "同步红利策略数据与页面"
git push origin main
```

说明：

- `git add .` 会提交普通代码、配置样例、文档和已跟踪的 SQLite 主数据库。
- `node_modules` 默认被 `.gitignore` 忽略；若需要把已安装依赖也同步到另一台电脑，额外执行 `git add -f factors\hongli_factor\node_modules`。
- 上传前可执行 `git status` 检查待提交文件。

### 上传 SQLite 数据库前的重要步骤

SQLite 在运行期间，最新写入可能暂存于 `-wal` 文件。上传前先把 WAL 安全合并进主数据库：

```powershell
cd E:\AI-Investment2\Investment
D:\Anaconda\python.exe -c "import sqlite3;c=sqlite3.connect('factors/hongli_factor/data/red_dividend_timing.sqlite');print(c.execute('pragma wal_checkpoint(TRUNCATE)').fetchone());c.close()"
```

随后再执行 `git add .`、提交和推送。主数据库文件为：

```text
factors/hongli_factor/data/red_dividend_timing.sqlite
```

不要上传这两个临时文件：

```text
red_dividend_timing.sqlite-wal
red_dividend_timing.sqlite-shm
```

它们不包含独立需要保存的内容；完成 checkpoint 后，数据已经进入主数据库。

## 二、在另一台电脑下载项目

首次下载：

```powershell
cd E:\AI-Investment2\Investment
git clone https://github.com/lightaochen/Investment.git
```

如果仓库已经存在，只需更新：

```powershell
cd E:\AI-Investment2\Investment
git pull --ff-only origin main
```

检查是否已获得数据库：

```powershell
Get-Item .\factors\hongli_factor\data\red_dividend_timing.sqlite
```

## 三、另一台电脑的 iFinD 凭据配置

`config/ifind.env` 包含账号密码，绝不能上传到公开 GitHub。另一台电脑应本地创建：

```powershell
cd E:\AI-Investment2\Investment\factors\hongli_factor
Copy-Item .\config\ifind.env.example .\config\ifind.env
notepad .\config\ifind.env
```

填写：

```text
THS_USERNAME=你的iFinD账号
THS_PASSWORD=你的iFinD密码
```

该文件已被 `.gitignore` 排除；执行 `git status` 时不应把它加入提交。

## 五、日更后的推荐顺序

```powershell
cd E:\AI-Investment2\Investment\factors\hongli_factor

# 1. 同步 iFinD 指数行情与股息率
D:\Anaconda\python.exe .\scripts\sync_ifind_red_dividend.py --daily

# 2. 同步十年期国债收益率等公开数据
npm.cmd run sync

# 3. 生成六个指数的股债收益差与标准差通道
$redDividendCodes = @('000824.CSI','000825.CSI','000826.CSI','000922.CSI','921468.CSI','931231.CSI')
foreach ($code in $redDividendCodes) {
  & D:\Anaconda\python.exe .\scripts\build_red_dividend_signals.py --index-code $code
  if ($LASTEXITCODE -ne 0) { throw "信号生成失败：$code" }
}

# 4. 合并 SQLite WAL 后上传
cd E:\AI-Investment2\Investment
D:\Anaconda\python.exe -c "import sqlite3;c=sqlite3.connect('factors/hongli_factor/data/red_dividend_timing.sqlite');print(c.execute('pragma wal_checkpoint(TRUNCATE)').fetchone());c.close()"
git add .
git add -f factors\hongli_factor\node_modules
git commit -m "日更红利策略数据"
git push origin main
```

## 六、常见检查命令

查看当前是否有尚未提交的文件：

```powershell
git status
```

查看最近一次提交：

```powershell
git log -1 --oneline
```

查看本地是否已经和远端一致：

```powershell
git status -sb
```

显示 `## main...origin/main` 且没有其他文件列表，表示本地与远端提交一致。

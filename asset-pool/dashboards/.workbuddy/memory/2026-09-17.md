## 贵州茅台护城河监控面板（承接宁德时代面板）

**用户的核心逻辑（后续复用）：**
- 宁德护城河货币化 = 单位 Wh 超额利润；茅台 = 消费者愿付的品牌溢价
- 三条溢价公式：P1=(批价−供货价)/供货价；P2=(终端成交价−批价)/批价；P3=(飞天批价−普五批价)/普五批价，**P3 最重要**（相对溢价才是护城河，行业整体跌不算）
- 六区域：市场价格 / 渠道库存(存销比) / 动销(Sell-through vs Sell-in) / 渠道利润(Dealer Economics) / 公司经营 / 品牌护城河 + 宏观 + 估值
- Moat Score 权重：品牌溢价 30% / 库存 25% / 动销 20% / 渠道经济 15% / 品牌趋势 10%

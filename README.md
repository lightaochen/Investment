# 价值投资操作系统

这是一个本地优先的价值投资知识系统初版。它把 Obsidian 作为私有知识库，把网页作为公开展示层。

## 当前包含

- `index.html`：网页入口
- `styles.css`：页面样式
- `app.js`：内容渲染逻辑
- `data/site-data.js`：示例内容数据
- `obsidian/templates`：视频、概念、公司、读书模板
- `workflow.md`：视频到网页的沉淀流程

## 使用方式

直接用浏览器打开 `index.html` 即可查看初版页面。

## 后续迭代方向

1. 将 Obsidian 笔记中的 `publish: true` 内容自动转成网页数据。
2. 接入音视频转写，生成视频入库模板。
3. 增加单篇文章页、单家公司页、概念详情页。
4. 增加指标追踪表和公司研究版本历史。
5. 部署为静态网站或升级为 Next.js/MDX 站点。

# Content Style

## Voice

- Sincere, rational, vivid, and learning-in-public.
- Speak like a thoughtful young financial IT worker, not a guru.
- Use concrete everyday examples before abstract concepts.
- Prefer “我理解的是” over “真相是”.

## Useful Patterns

- “不是A，而是B”
- “看起来是资产，其实可能是负债”
- “问题不是有没有收入，而是收入有没有沉淀成资产”
- “这不是投资建议，只是我的学习笔记”

## Avoid

- Overconfident predictions
- Direct buy/sell language
- Course-selling tone
- Dense textbook explanations

# Compliance

## Required Boundary

Use:

```text
不荐股，不预测，不构成投资建议。
```

## Risky Expressions

Avoid:

- “可以买”
- “一定上涨”
- “稳赚”
- “目标价”
- “确定跑赢”

## Data Rules

For index returns or financial data, specify:

- start date
- end date
- dividend treatment
- currency
- investment frequency
- fees and taxes

When data is not verified, mark it as `待核验`.

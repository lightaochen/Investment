# HTML Style

## Visual Identity

- 9:16 vertical cards.
- Warm off-white background.
- Dark green text.
- Gold highlights.
- Thin borders.
- Subtle grid texture.
- Calm research-note feeling.

## Slide Rules

- One slide, one point.
- Use a large headline.
- Use short, punchy supporting text.
- Prefer cards, formulas, ladders, comparisons, and flows.
- Leave breathing room for screenshot and video zoom.

## Common Components

- Title slide
- Formula slide
- Comparison slide
- Flow diagram
- Asset map
- Risk checklist
- Final summary

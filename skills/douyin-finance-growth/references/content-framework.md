# Douyin Finance Growth Framework

## What has worked so far

- Ordinary people’s questions outperform abstract philosophy.
- Concrete assets and life situations perform better than pure worldview content.
- Titles with clear tension or contradiction are easier to click.
- Real voice or voice-like delivery builds more trust than pure AI narration.
- Comparison posts are stronger when they map directly to a real choice.

## Best-performing topic patterns

- X 一定是资产吗？
- 普通人为什么先理解 X？
- 为什么 X 比 Y 贵？
- 普通人财富自由的第一步
- 功能 vs 情绪

## Content formula

1. Hook with a problem the audience already feels.
2. Make the conflict visible.
3. Use one concrete example.
4. Explain the logic in plain language.
5. End with a decision or next action.

## Format rule of thumb

- Need trust -> voiceover / live voice / avatar口播
- Need comparison -> image carousel
- Need explanation -> cards plus short narration
- Need strong recognition -> short title, large type, clear contrast

## Iteration rule

Only test one main variable per post:

- title
- hook
- format
- topic bucket
- narration style
- cover style

## Review questions

- Did the title immediately connect to ordinary people?
- Was there a concrete asset, company, or life case?
- Was the format easy to trust?
- Did the ending give an action or decision?

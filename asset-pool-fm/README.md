# 资产池原型

这是个人/家庭资产池的离线网页原型。

## 使用方式

直接用浏览器打开 `index.html` 即可。数据保存于当前浏览器的 Local Storage；支持在“数据与设置”中导出和导入 JSON 备份。

## 当前能力

- 通过新增交易创建或更新资产，资产列表是交易和现金流的汇总结果
- 负债、现金流和交易录入
- 买入、卖出、分红会自动更新资产持仓、成本、估值和已实现收益
- 交易记录支持修改和删除；资产结果会从交易流水重新计算，避免数据互相矛盾
- 交易历史显示全部记录，并支持按标的、类型、日期范围和关键词筛选
- 现金流支持修改和删除，内置房租、餐饮、日用品、礼赠、非必需消费等类别，并可自定义新增类别
- 可单独录入资产分红、派息、租金、利息等现金流；资产月现金流优先按最近一年合计除以 12 自动折算
- 资产页拆分成本、总收益、历史总分红、近一年现金流和月现金流；总收益 = 价差收益 + 分红/租金
- 支持手动更新最新价；后续可接入 Tushare 等免费行情源
- 资产现金流覆盖率与成长地图
- 投资原则、复盘和视频链接思想库
- 本地备份恢复

## 原型边界

这不是正式的加密财务软件：它没有数据库加密、账号体系、自动行情或券商连接。当前最新价需要手动更新；正式产品下一步将迁移为 Tauri + SQLite 加密数据库的桌面应用，并把 Tushare 行情能力设计成可选增值入口。

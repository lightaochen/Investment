# 第十期卡片 02：核心反差

Style: `bold`
Layout: `comparison`
Palette: `warm`

Goal:
用最短的视觉语言讲清楚：Molly U盘卖的是功能，盲盒卖的是情绪、期待和身份感。

Canvas:
竖版 4:5，适合抖音图文封面和中间页。

Visual direction:
- 左侧是冷静克制的 Molly 联名 U盘，标签写“功能”
- 右侧是高情绪价值的盲盒玩具，标签写“情绪”
- 中间用强对比的分割线
- 左边颜色偏灰蓝、工业感
- 右边颜色偏暖金、跳色、带惊喜感
- 整体要像一张能直接看懂的商业认知海报

Text on card:
- Molly U盘：卖功能
- 盲盒：卖情绪
- 功能能比价
- 情绪会溢价

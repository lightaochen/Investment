# 第十期封面

## 主题
为什么 Molly + U 盘只能卖几十，Molly + 盲盒却能卖上百？

## 目标
做成一张更接近参考图风格的抖音自媒体封面：信息密度更高、对比更强、层次更丰富，但主页缩略图仍然能读懂。

## 风格
- bold / screen-print 风格
- comparison 布局
- 黑底 + 蓝金对比
- 商业海报感，强冲击，带一点“被看穿”的感觉

## 画面要求
- 9:16 竖版
- 核心标题放在上半区，尽量保留参考图那种超大字重和强对比
- 左右双栏对比：左边功能，右边情绪
- 中间有明显的 VS 对撞感
- 左侧用冷蓝色、网格、功能图标、U 盘、低价标签
- 右侧用金色光效、星星、泡泡、盲盒、溢价标签
- 底部保留一句总结金句，短而有力
- 所有关键元素都在中间 70% 安全区内
- 标题不宜太碎，但可以分两行，字要大

## 文案
为什么 Molly+U盘
只能卖几十？

为什么 Molly+盲盒
却能卖上百？

## 侧边标签
左侧：功能 / 存储文件 / 传输数据 / 安全稳定
右侧：情绪 / 拆盒惊喜 / IP 认同 / 收藏价值

## 底部金句
商业本质：产品提供功能，品牌贩卖情绪。

## 需要传达的气质
- 冷静但锋利
- 有商业洞察
- 视觉上更像爆款封面，不像讲义
- 保留参考图那种“标题压顶 + 视觉分栏 + 金句收尾”的结构
